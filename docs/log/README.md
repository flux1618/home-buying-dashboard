# Engineering log

Dated entries describing what was built, what broke, and what was decided. One file per
working day, newest first in the table below.

This is not a changelog. A changelog says what changed; these entries say **why**, and they
record the bugs honestly — including the ones that were embarrassing, because those are the
ones with something to teach. Where a day produced a consequential architectural choice, the
entry links to the [ADR](../adr/README.md) rather than re-arguing it.

Every entry ends with a section listing what is still unverified or unfinished. If an entry
has nothing in that section, it is probably not being honest.
